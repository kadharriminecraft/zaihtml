The full app — chat, files, everything — streams into a locked frame inside this file. Your phone never opens a blocked page: this file pulls every byte quietly through your worker, and organization filters only intercept page visits, which this never makes. For sending prompts, live streams, the model picker, staying logged in, passing the security-verification slider, keeping the sign-in after the file closes and automatic retry when a model is busy, the relay must be zp service 6.7 or newer (check relay above) — older relays leave the model list empty, hang the first send forever, sign you out on the settings pages, reject every solved security puzzle, lose the sign-in on every reopen and make you resend busy models by hand until the site demands verification.

checking what this phone remembers…
Some phone file viewers wipe all saved data the moment this file closes — that is why signing in never stuck. Your relay can keep an encrypted copy of your sign-in, locked by the secret you type above (the relay only ever stores encrypted bytes; without the secret nobody — not even the relay — can use them). Back up once while signed in; after any wipe, type the same secret and tap Restore.

If it ever stops working
  1. If the app view shows an error card, tap Retry — often just a weak network moment.
  2. Make sure you're online, then tap Check relay above.
  3. If the relay stays unreachable while you are online, this network is probably blocking its address. Deploy the same worker code in Cloudflare under a new name (a new address), tap Change relay address above, and paste it — this file itself never needs rebuilding.
  4. This file never expires and never needs the network just to open.
