How to use it
  1. Tap Copy below, open any notes app, paste, and save it as zai-pocket.html — or just tap Save the file.
  2. Open it from Downloads / Files on your phone.
  3. Tap Open Z.ai in this file — the app streams into a locked frame inside the file. Your phone never opens a blocked page: filters intercept page visits, and this file never makes one. Every byte arrives as an opaque token through your worker.
v6.1: the baked relay address is only the first candidate. The file probes a relay registry (the baked address plus any you add, remembered on your phone) and auto-fails-over between them. If every relay dies, the error card shows a per-address diagnosis and a paste box to switch relays inline. The phone's browser never opens any relay as a website — it only fetches opaque tokens through it, which page-visit filters do not intercept.

2zai-proxy-worker.js — the Cloudflare worker

Deploy it (one-time, about 2 minutes)
  1. Tap Copy below — the whole worker code goes to your clipboard.
  2. Go to dash.cloudflare.com → Workers & Pages → your worker (zaihtml) → Edit code.
  3. Select all in the editor, paste, then Save and Deploy.
  4. Check it: open your-worker.workers.dev/__status — it should say zp service 6.0.
v6 relay: credentialed CORS (sign-in works), path-preserving /__o/ handles with an injected base tag (lazy route chunks load — no dead buttons), sandbox-safe SPA routing, opaque tokens everywhere (no readable hostname in any request URL), neutral root page so the address cannot be content-classified. The app file is a v6.1 pocket: switchable relay + auto-failover.
If the relay address ever stops answering on your phone
  1. Open the pocket file — the app view will show an error card with a per-address diagnosis (unreachable / timed out / answered with an error).
  2. If it says unreachable while you are online, your network is probably blocking that address. Fix it in 2 minutes, no chat needed: in Cloudflare go to Workers & Pages → Create → Worker → give it any NEW name (for example zr-relay-2), edit its code, paste this same worker code, deploy.
  3. The new worker has a brand-new address (new-name.your-account.workers.dev). In the pocket tap Change relay address (home screen) or Switch relay address (error card) and paste the new address.
  4. The file remembers it. Old address blocked forever? Irrelevant — the file now uses the new one. Repeat any time it happens again; the code never changes.
